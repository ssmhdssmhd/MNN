欢迎使用 MNN.Chat！

【版本公告】
当前版本：v0.0.11

【新增功能】
1. 底部导航栏新增「设置」标签页，可直接管理 API 服务
2. API 服务支持多模型选择，可在设置中勾选多个模型通过 API 调用
3. API 设置中新增服务启动/停止/重启按钮
4. 关于页新增开发者信息与公告

【使用提示】
- API 服务需在对话页加载模型后启动，退出对话页将自动关闭服务
- 可在 设置 -> API 模型选择 中勾选需要对外暴露的模型
- 访问 http://<设备IP>:8080/ 可打开内置测试页面，支持模型切换

感谢您的使用，如有问题请在 GitHub 仓库提交 Issue。
